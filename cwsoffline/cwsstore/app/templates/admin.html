Review before distribution

    

    Windows: paste the compact GPO JSON into "Extension management settings", or import the .reg into a machine registry for direct testing (it is not a GPMC/GPO import), or review the PowerShell script and run it on a management workstation to merge ExtensionSettings into your existing named GPO. Linux: deploy the managed-policy JSON. The allowlist/forcelist downloads are legacy references: ExtensionSettings overrides those legacy policies, so never deploy both strategies together. The store only generates these files and never touches your domain; reviewing and running the PowerShell script changes the named GPO.
